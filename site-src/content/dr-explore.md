## What it does

You give it a question and a short brief. It scans broadly, follows the most promising threads, and sends a separate scout to look for non-obvious links to other fields. Findings are written to a run folder as it works, so a long session does not depend on one context window. It has no independent claim check, so use it for discovery rather than for work others will challenge.

## Where it came from

dr-explore is the exploratory half of a deep research skill that was split in two. It keeps the original phases: brief, scan, deep dive, then challenge and expansion. The lateral-thinking scout is a separate set of instructions that ships inside the skill. It was ported from a private skill library and has been edited in this repository since.
