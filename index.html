skill-suites

Agent Skills suites are groups of skills that work together, and each skill installs on its own. Every skill is a self-contained directory in the Agent Skills format. An installed skill never reads outside its own directory.

Suites#

  • ops-

    Plans, orders, runs, and learns from multi-skill efforts across your installed skills.

    6 skills

Install#

List the skills available in the repository:

npx skills add shinytoyrobots/skill-suites --list

Install one skill by name. Repeat --skill to install several at once:

npx skills add shinytoyrobots/skill-suites --skill <name>

Each suite page lists the full install command for that suite.
